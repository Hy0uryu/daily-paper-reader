## 摘要
本文提出了一种用于双足行走的多阶段全身模型预测控制方法，该方法将近预测时域的详细全身模型与远预测时域的简化单刚体模型相结合。这种方法在保留预测能力的同时降低了计算复杂度。所产生的非线性最优控制问题在 acados 中使用序列二次规划 (SQP) 求解。利用预先指定的接触计划和目标步行速度，该控制器在不依赖预选落脚点位置的情况下优化关节扭矩。该控制器在 MuJoCo 仿真中通过 18 自由度双足机器人 HyPer-2 进行了验证。

## Abstract
This paper presents a multi-phase whole-body model predictive control approach for bipedal walking, combining a detailed whole-body model in the near horizon with a simplified single-rigid-body model in the later prediction steps. This reduces computational complexity while retaining prediction capabilities. The resulting nonlinear optimal control problem is solved using sequential quadratic programming (SQP) in acados. Using a prior specified contact schedule and a target walking speed, the controller optimizes joint torques without depending on prior selected foot step locations. The controller is validated in MuJoCo simulation on the 18-DoF bipedal robot HyPer-2

*   **背景与动机**：

### 2. 论文提出的方法论
*   **核心思想**：将 MPC 的预测时域分为两个阶段。
    *   **第一阶段（全身模型 WB）**：在预测的前 $N_{wb}$ 步，使用完整的 18 自由度动力学，考虑关节扭矩、关节限位和精确的足端运动学。
    *   **第二阶段（单刚体模型 SRB）**：在随后的 $N_{srb}$ 步，将机器人简化为具有集中质量和惯量的单刚体，仅优化质心运动和足端位置。
*   **关键技术细节**：
    *   **多阶段优化**：通过一个转换映射（Transition Map）将 WB 阶段的末端状态（关节位置/速度）映射为 SRB 阶段的初始状态（浮动基座状态）。
    *   **非线性优化求解**：使用 **acados** 框架，采用**序列二次规划（SQP）**算法。为了保证实时性，每个控制周期仅进行少量的 SQP 迭代。
    *   **约束处理**：包括摩擦力锥约束、接触计划（预设步态周期）、无滑移约束以及关节位置/速度/扭矩限位。
    *   **代价函数**：WB 阶段侧重于关节正则化和足端轨迹跟踪；SRB 阶段侧重于基座速度和足端位置参考。

### 6. 论文的主要结论与发现
*   **迭代次数**：对于双足行走，**3 次 SQP 迭代**足以获得“足够好”的解，继续增加迭代次数对降低成本函数和减少误差的边际贡献很小，但会显著增加耗时。
*   **模型组合**：WB 阶段占比 $\alpha$ 在 0.3 到 0.6 之间时，机器人表现最稳定。若 WB 占比过低（$<0.2$），机器人会失稳；若过高，则计算超时。
*   **预测时界**：预测时界的总长度对稳定性至关重要，过短的预测会导致膝盖弯曲或摔倒。

### 7. 优点
*   **计算高效**：通过级联模型显著降低了全动力学优化的负担，使其能在 100Hz 下运行。
*   **无需预设落脚点**：控制器能够在线优化足端位置，比传统的基于启发式落脚点（如 Raibert Heuristic）的方法更具通用性。
*   **工程落地性强**：使用了通用的开源优化框架 acados，而非高度定制的私有求解器，便于其他研究者复现和应用。
